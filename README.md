# StyleRush 🛍️

StyleRush is a simple shopping app where users can order clothes online and get them delivered within **30–60 minutes**.

This is our mini project. We designed the app in Figma first and then made it as a website using HTML and Bootstrap.

## Links
- **Figma design:** https://www.figma.com/design/mWd2aN091HLipGgx1BCnMw/StyleRush-Shopping-App
- **Figma prototype:** https://www.figma.com/proto/mWd2aN091HLipGgx1BCnMw/StyleRush-Shopping-App
- **Live website (HTML + Bootstrap):** https://26sheikhza-create.github.io/StyleRush/

## Tech Used
- Figma (wireframe, UI design, prototype)
- HTML
- CSS
- Bootstrap 5
- Bootstrap Icons
- JavaScript (size select, cart quantity and total)

## How to Run
1. Clone or download this repository
2. Open the folder in VS Code
3. Open `index.html` in a browser (or use Live Server)

Or just open the live website link above.
